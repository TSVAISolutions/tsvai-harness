# Code Review Standards

Standard practices for code review and quality assurance.

## Review Checklist

- Code follows architectural rules
- Tests are comprehensive
- No security vulnerabilities
- Performance is acceptable
- Documentation is complete
- Commit messages are clear

## Review Levels

**Low**: Quick checks
**Medium**: Balanced review
**High**: Comprehensive review
**Ultra**: Deep multi-agent review

## Approval

Minimum: 1 review approval required
Emergency: 2 reviews required for production

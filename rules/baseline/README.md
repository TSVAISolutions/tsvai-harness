# Baseline Rules

Foundational rules and patterns for TSVAI development and operations.

## Structure

- `backend/` - Backend service rules
- `frontend/` - Frontend application rules
- `global/` - Cross-cutting concerns

## Purpose

Baseline rules establish standard practices that apply unless explicitly overridden by consilient or context-specific rules.

## Usage

Rules are referenced in CLAUDE.md and enforced by CI/CD workflows and agent coordination.

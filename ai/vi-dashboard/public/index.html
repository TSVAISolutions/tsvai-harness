Harness Factory

The operating system of Harness Factory Intelligence. A monorepo that aggregates all Harness Factory repositories as submodules and hosts the AI packages that wrap the platform.

What is Harness Factory

Harness is the central orchestration system for the entire Harness Factory ecosystem. It provides:

  • Unified monorepo access - Git submodules across all Harness Factory repositories
  • AI layer integration - Brain-Wiki, Army-Agents, Consilient, and more
  • Knowledge management - Centralized context docs and deployment guides
  • Agent coordination - Multi-agent registration and conflict prevention
  • CI/CD automation - Plugin builds and Kubernetes deployments

Structure

harness-factory/ ├── ai/ # AI LAYER │ ├── brain-wiki/ # Knowledge base │ ├── cli/ # CLI interface │ ├── plugin/ # Core plugin system │ └── [more components]/ ├── submodules/ # All Harness Factory repos │ ├── frontend/ │ ├── backend/ │ └── platform/ ├── context/ # Documentation └── k8s/ # Kubernetes manifests

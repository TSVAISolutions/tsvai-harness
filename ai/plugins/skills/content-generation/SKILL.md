# Content Generation Skill

> Generate and create content with TSVAI AI capabilities

## Overview

Create and generate content including summaries, expansions, and rewrites.

## Capabilities

- Text summarization
- Content expansion
- Text rewriting and paraphrasing
- Template-based generation
- Multi-language support

## Usage

```javascript
// Summarize text
const summary = await contentGenerator.summarize(text, {
  length: 'short',
  style: 'bullet-points'
});

// Generate content from template
const content = await contentGenerator.generate(template, {
  variables: { title, topic }
});
```

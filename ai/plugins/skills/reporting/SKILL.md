# Reporting Skill

> Generate comprehensive reports and insights from TSVAI data

## Overview

Generate reports, dashboards, and insights from processed data.

## Capabilities

- Report generation (PDF, HTML, markdown)
- Dashboard creation
- Statistical summaries
- Visualization preparation
- Export functionality

## Usage

```javascript
const report = await reportGenerator.create(data, {
  format: 'pdf',
  template: 'standard',
  includeCharts: true
});
```
